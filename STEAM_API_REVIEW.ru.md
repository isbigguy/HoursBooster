# Проверка интеграции Steam — 30 октября 2026

Проверены только используемые вызовы в `client.ts`, `manager.ts` и `session_store.ts`,
их вызывающие обработчики и исходники установленных библиотек. Приложение работает
через клиентский протокол Steam и авторизацию Steam; ключ публичного Web API для
текущих функций не требуется. Это сторонние библиотеки, а не официальный SDK Valve.

## Вызовы и исправления

| Назначение                | Используемый API                                                          | Результат                                                                                                                                                                                                         |
| ------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Вход с паролем            | SteamUser.logOn, steamGuard, generateAuthCode                             | Код 2FA передаётся только при входе паролем; callback одноразовый и очищается при остановке/ошибке.                                                                                                               |
| Повторный вход            | logOn({ refreshToken })                                                   | Сохранённый seed больше не добавляет несовместимый twoFactorCode. Формат и аудитория JWT проверяются до асинхронного разбора библиотекой; подлинность проверяет Steam.                                            |
| Запуск/выход              | logOn, logOff, loggedOn, disconnected, error                              | Операции одного аккаунта идут последовательно. Повторный Start не вызывает второй вход. Stop ждёт завершения выхода; для следующего запуска создаётся новый клиент. Поздние события старого клиента игнорируются. |
| Восстановление соединения | автоматический reconnect steam-user                                       | Сохранено штатное восстановление. Промежуточный disconnected не разрешает параллельный вход.                                                                                                                      |
| Игры и статус             | gamesPlayed, setPersona                                                   | Сигнатуры совместимы. Строковый customTitle означает отдельную non-Steam игру, а не переименование AppID.                                                                                                         |
| Чат                       | chat.friendMessage, chat.sendFriendMessage                                | Убраны устаревшие входящий обработчик и метод отправки. Исходящее сообщение сохраняется после подтверждения Steam; ошибка не выглядит успешной отправкой.                                                         |
| QR                        | LoginSession(SteamClient), startWithQR, authenticated, cancelLoginAttempt | Платформа выдаёт токен для клиентского входа. Сохраняются ограничения количества, срок действия, владелец и одноразовое получение результата.                                                                     |

## Проверки и границы результата

- 22 автоматические проверки: прежние проверки безопасности и 9 новых проверок Steam.
  В тестах входа используется настоящий steam-user с отключённым сетевым транспортом;
  проверки очереди используют настоящие SQLite и шифрование с подменённым клиентом.
- Проверены типы, форматирование и production build.
- В настоящем Deno production-процессе получен живой QR challenge Steam (`s.team`),
  проверены ожидание, отмена и HTTP 404 после отмены. QR и токены не включены в журнал.
- Настоящий пароль, сканирование QR, доставка сообщения и начисление часов не проверялись:
  для этого нужен ваш аккаунт. Тесты не подтверждают фактическое начисление часов.
- Фиксированного списка IP нет: клиентские серверы обнаруживаются через Steam Directory.
  Полученный живой список содержал 51 сервер; один из WebSocket-адресов находился в
  домене `steamserver.net`. Этот результат не является полным перехватом трафика.
- Docker Engine в среде проверки отсутствует; контейнерная сборка и Linux-запуск
  не проверены. Нельзя считать их подтверждёнными успешным запуском Deno в Windows.
- Minimus сообщил об отключении своего реестра 22 октября 2026:
  [официальное объявление](https://www.minimus.io/get-started).
  Dockerfile не переведён на недоступный реестр; текущие закреплённые базы сохранены.

Настройки продления refresh tokens оставлены штатными: принудительное обновление
инвалидирует прежний токен, поэтому оно не включалось без отдельной необходимости.
